About This Website

This is a free, open-source practice tool to help you prepare for the Kubernetes Cloud Native Associate (KCNA) certification exam. It contains 258 multiple-choice questions covering all four exam domains — Kubernetes Fundamentals, Container Orchestration, Cloud Native Application Delivery, and Cloud Native Architecture — weighted to match the official exam blueprint.

The app runs entirely in your browser with no backend, no tracking, and no sign-up required. Pick your question count, take the exam, and review detailed explanations for every question when you're done.
